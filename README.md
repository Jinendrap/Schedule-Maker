# Schedule-Maker
Upload the Excel sheet of all the specializations timetable and this tool will give you all the possible variations of the specific subjects and divisions you will choose.

How to use: all the instructions are available in the tool, if need more help, feel free to reach out to me.

Imp: This is not an official tool by any university, this is a private project created to find the diifferent alternatives available for the schedule. This tool can make mistake, please double check the responses.
